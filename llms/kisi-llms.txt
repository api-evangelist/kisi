# Kisi

> Kisi is a cloud-based physical access control platform — hardware controllers/readers plus software — for managing building access, doors, elevators, visitor management, video surveillance, and security analytics. The Kisi API (OpenAPI 3.1, production host https://api.kisi.io) exposes 227 operations across 47 resource families for organizations, places, doors/locks, groups, members, cards, controllers, readers, events, and reports.

## Conventions & Semantics
- [Conventions](conventions/kisi-conventions.yml): JSON-only, header auth, offset/limit pagination (X-Collection-Range), no idempotency-key.
- [Authentication](authentication/kisi-authentication.yml): apiKey (Authorization header) + OAuth2 authorizationCode.
- [OAuth Scopes](scopes/kisi-scopes.yml): OAuth2 authorizationCode flow (authorize/token at api.kisi.io).
- [Rate Limits](rate-limits/kisi-rate-limits.yml): 5 req/s per user; 429 on exceed; custom limits on event_sets and signed_upload_urls.
- [Error Codes](errors/kisi-error-codes.yml): 70 application error codes ({code,error} envelope).
- [Problem Types](errors/kisi-problem-types.yml): HTTP 4xx/5xx catalog derived from OpenAPI.
- [Lifecycle](lifecycle/kisi-lifecycle.yml): RFC 8594 Deprecation/Sunset headers; status page.
- [Data Model](data-model/kisi-data-model.yml): Entity/relationship graph.
- [Conformance](conformance/kisi-conformance.yml): OAuth2, RFC 8594, webhook signing; not RFC 9457.
- [Agentic Access](agentic-access/kisi-agentic-access.yml): Recommended x-agentic-access contracts per operation.
