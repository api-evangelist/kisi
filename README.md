Kisi is a cloud-based physical access control platform that combines hardware controllers and readers with software dashboards and a full REST API to manage building access, doors, locks, elevators, groups, members, access cards, visitor management, video surveillance, and security analytics. The Kisi API (OpenAPI 3.1, production host https://api.kisi.io) exposes 227 operations across 47 resource families, with header/OAuth2 authentication, offset/limit pagination, documented rate limits, RFC 8594 deprecation signaling, and a published Trust Center (SOC 2 Type 2, ISO/IEC 27001:2022, GDPR, NDAA). Kisi is a Point Nine portfolio company; this profile was enriched from Kisi's public developer surface.

**Areas:** Company · Physical Access Control · Security · Identity · IoT · Building Management · Access Control · Software-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for KISI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
